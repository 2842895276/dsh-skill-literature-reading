# 简化文献卡片（REL- / METH- 专用）

> 用于**相关方向**和**方法工具**类文献。
> 这类文献是浏览性质，**不要逼自己填满九段**——填了也不会看。

---

## REL- 相关方向

```markdown
---
编号: REL-XXX
标题:            # 论文原题
英文标题:        # 查重用，转小写去标点
领域:            # 如"云计算"、"5G网络"、"IoT"
链接:            # DOI 优先；没有就填 arXiv 号或页面 URL
链接状态:        # ✅全文 / ⚠️仅摘要 / ❌打不开
PDF:
读法:            # 浏览 / 略读 / 精读
日期:
---

## 一句话
## 和我的方向有什么关系
## 有什么可借鉴的
## 值不值得再深入
```

---

## METH- 方法工具

```markdown
---
编号: METH-XXX
标题:            # 论文原题
英文标题:        # 查重用
是什么工具:      # 如"深度强化学习"、"凸优化"、"排队论"
链接:            # DOI 优先
链接状态:
PDF:
读法:            # 浏览 / 略读 / 精读
日期:
---

## 一句话：这个工具解决什么类型的问题
## 能怎么用在我的方向上（给 2 个具体场景）
## 需要什么前置基础
## 值不值得现在学
```

---

## 为什么简化

读一篇 5G 网络的综述，你不需要知道它的实验用了几个基站——那和你的课题无关。

**需要记住的只有三件事**：
1. 它大概讲什么
2. 和我的方向有没有关系
3. 要不要再深入

填满九段只会让你花 40 分钟在一篇"了解一下"的论文上，然后下周就忘了。

> ⚠️ 但 **`英文标题` 和 `链接` 不能省**——那是下次查重的唯一依据。
> 没 DOI 就填 arXiv 号或论文页面 URL；实在都没有，填「无」并在下方备注原因。
