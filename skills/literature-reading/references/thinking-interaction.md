# 思考互动

这是阅读中的可选互动强度，不替代 A–F 读法，也不改变保存授权。用户未选择或旧配置缺字段时用“直接讲解”；首次偏好入口可推荐轻量互动，但不自动开启。用户主动请求讨论或反问可在本次启用，不默默更改长期配置。

## 强度与节奏

| 强度 | 行为 |
|---|---|
| 直接讲解 | 不主动提出练习性问题；仍回答用户问题，必要的任务澄清不受限 |
| 轻量互动 | 在关键逻辑讲完后择机问一个问题，一篇通常 1–3 个节点，不是配额 |
| 深入讨论 | 沿用户的理解与兴趣逐步追问方法、条件、证据和验证方案，不遍历题库 |

先讲必要知识，再问；允许看原文作答，不考背诵。一次只问一个问题，停下来等待，不能同轮自问自答或附操作字母菜单造成两个待答入口。用户回答后先反馈，再决定继续还是追问，不必每次反馈后再出题。用户说“继续/跳过”就结束当前提问并推进；“直接讲/不问了”停止本次主动提问，“以后不提问”才保存长期偏好。暂停立即停止讲解，保存处理按 save-policy.md，不追加总结题；要求一次完整讲解时不被互动打断。

互动问题优先用自然语言；如给辅助选项，明确当前为“思考题”，字母只解释为该题答案，不套用阅读操作菜单。恢复阅读时按实际需要再展示操作菜单。未回答不能记录为理解或能力不足。

## 按内容选问题

| 层次 | 问法示例 | 目的 |
|---|---|---|
| 自己的理解 | 不用专业术语，你会怎样解释这篇论文要解决的问题？ | 重组问题、方法与结果，而非复述摘要 |
| 方法理由 | 作者为什么加入这个约束？它在方法中起什么作用？ | 联系设计与目标 |
| 替代方法 | 如果由你解决，先试什么办法？简单规则也可以。 | 形成其他解决路径 |
| 方法取舍 | 换成你的办法，可能改善什么，又付出什么代价？ | 比较条件、成本与收益 |
| 条件与证据 | 若这个假设不成立，结论还成立吗？现有证据能说明吗？ | 区分已验证与未知 |
| 后续研究 | 这个未评估场景值得研究吗？怎样检验你的判断？ | 将疑问变成可验证问题 |

示例是问法，不是对任何论文的事实判断。粗读关注问题与价值；精读讨论方法、替代方案和证据；科研分析再讨论文献差异与验证设计；补基础先帮助解释概念，不急着要求创新。

问题过宽时缩小到具体场景。例如先问“凭直觉怎样选服务器位置”，用户提出“放在用户多的地方”后，再讨论多个密集区与预算约束；不能把教学例子写成论文实验。想不到时先给提示，再提供两种方案供比较；仍不愿回答就解释并继续，不层层逼问。

## 反馈与研究判断

1. 具体指出正确之处，不以笼统赞美代替判断。
2. 对遗漏或误解给原文依据、条件或明确标注的反例；必要时给提示，留出修正机会，不立即代写全部答案。
3. 协助组织清楚的表达，保留用户本意；AI 新补的论据、方法与想法单独标明。用户不同意改写时沿用其实际观点并保留分歧。
4. 对研究设想按需要逐步看“是否重要、已有证据是否回答、怎样验证、是否可行”。验证可讨论变化因素、比较对象和指标，不要求一次答齐。未经相关文献核查，新颖性记待核实，不称已发现创新点。

未涉及不等于缺陷。核实相关原文后才能说“文中未评估”；未核实称待查疑问。区分作者限定的范围、证据不足及论证问题。允许用户认为扩展不重要，并讨论理由；不强凑局限、空白或研究想法。读完仍只留一个疑问也是有效成果。

收尾可邀请用户任选一个方向表达：解决了什么及成立条件、仍需核实什么、什么问题值得验证。轻量模式已有充分互动则不另加必答收尾题；用户要求结束/保存时先完成原任务。

## 思考记录（仅获保存授权时）

CORE/REL/METH 均可在原文献卡中按需加入“思考记录”，只保留有内容的字段：

- **我的理解**：用户表述及其认可的修正；AI 给出的参考解释另标“AI 补充，用户尚未确认”，不能冒充用户理解。
- **待核实问题**：疑问、相关原文位置或待核实状态、后续核查方向。
- **研究线索**：提出者（用户提出/AI 建议/共同讨论）、设想、已有条件、可能验证办法及新颖性待核实项。

明确保存或已开启自动保存的完整讨论节点按 save-policy.md 写入；研究线索详细字段和跨历史检索按 [research-tracks.md](research-tracks.md)。保存讨论要点，不存逐字问答；同义问题增量合并，保留用户笔记与观点变化，不重写成 AI 观点。与“我的判断/未解问题/待办”重合时复用原段或引用位置，不重复复制。没有内容不创建空字段。必要时在阅读进度中记当前未完成的讨论和下一步，跨会话按已保存范围恢复。

知识卡仍只负责概念、方法和工具的解释与用法，不因提问自动建卡。学习变化沿用 growth.md：准确复述只支持相应知识点，选择答案或重复 AI 的话不足以证明独立理解；不自动评分、升级阶段或生成选题。

## 读取与成本

复用已读原文与会话，不为了出题扫描整个库；需要跨论文判断时才按用户范围和历史规则读取。讨论过的点不反复提问，保存仅增量记录结论与疑问。直接讲解且无思考内容要保存时，不加载本参考。
