# 输出格式与 PDF 中间文件

适用于聊天讲解、文献卡、知识卡、研究线索、索引、配置和导出笔记；格式要求不能只用于知识卡。

## 数学与 Markdown

- 保存 Markdown 用 UTF-8。独立公式以单独成行的 `$$` 包围，前后留空行；行内公式用 `$...$`。不要用反斜杠方括号/圆括号作为保存文件的公式边界。聊天按宿主支持的数学格式输出，写入文件时转换为上述格式，不直接照搬聊天标记。
- 公式不能包在反引号、代码围栏或四空格缩进中；代码示例除外。复杂公式移出表格，变量附白话说明。渲染不支持行内公式时可把复杂表达式改成独立公式，简单变量用普通文本，不盲目修改用户编辑器设置。
- 保留 LaTeX 命令的反斜杠，写文件使用不把 `\t`、`\n` 等误转为控制字符的字符串方式；不得出现双重转义、丢失反斜杠或未配对分隔符/花括号。
- 标题、段落、列表和围栏之间正确换行；表格列数一致，单元格内竖线正确处理，避免把复杂多行公式塞入表格。YAML 元数据用合法值，含特殊字符时正确引用。
- 本地卡片间链接使用真实相对路径；来源保留可核实位置。不要把聊天专用引用标记、内部工具 ID 或 UI 指令写入普通 Markdown 文件。

## PDF 提取质量

TXT 是检索辅助，不是公式的权威来源。提取结果出现乱码、符号丢失、上下标错位、双栏串行或表格错列时，回到对应 PDF 页面/渲染图核对，再重建公式与数字；不能把损坏文本原样写成笔记。无法确认则标待核实，不猜符号、指数或不等号方向。

## 写入检查

保存前检查新增/修改部分的公式、表格、链接与字符；保存后回读确认实际写入内容。具备目标编辑器预览或兼容渲染工具时核验代表性的复杂公式与表格。只有静态检查时明确没有验证实际渲染，不声称所有编辑器均兼容。用户报告乱码时先区分提取错误、编码错误和未渲染，修正相关内容并保留用户笔记。

## 临时文件

PDF 提取文字和页面图片可放授权项目的 `tmp/pdfs/` 下，按论文标识分子目录，避免不同论文都写 `page-01.png` 造成覆盖。它们是可重新生成的处理中间文件，不是原文归档或阅读卡片，不计入历史文献。

首次产生时简短说明用途与清理时机：阅读结束且保存成功后自动清理本次缓存；暂停或保存失败先保留，可说“这次保留临时文件”。正式笔记引用原 PDF 页码，不把可清理缓存当唯一证据来源。保留缓存不代表已保存阅读进度。

### 完成后自动清理

- 默认启用事件式清理，不是后台定时任务。仅用户明确结束本篇阅读或切换到另一篇，且本篇新增笔记、进度及线索已全部成功保存并回读核验后执行；原文按所选归档策略已完成或明确无需归档。粗读也可作为完成的阅读范围，不要求标成精读。
- 普通自动保存节点、单独“保存”、暂停/保存后暂停、待答问题尚未结束、无保存授权、保存或原文归档失败时不清理。换篇但拒绝保存时也保留。用户明确“保留临时文件”优先；不阻塞继续阅读。
- 生成时在会话维护本次创建文件的准确绝对路径清单；使用唯一的任务子目录，不覆盖原有文件。跨会话缺清单时，不按文件名、扩展名或时间猜测所有权，不自动清理旧缓存。旧文件只有用户明确要求且核实来源后才处理。
- 删除前解析每个文件及父目录的最终路径，确认位于当前授权项目的 `tmp/pdfs/` 内；存在符号链接、目录联接或边界不明时跳过。逐个使用绝对路径删除清单中的文件，不递归删除整个 tmp/pdfs、通配清空或移动目录。
- 核查项目保存的笔记/卡片/索引是否引用候选缓存（按候选路径与文件名定向搜索，不加载全文）；被引用、用途不明、仍被其他阅读任务使用或无法核查的文件保留。不要为清理擅自改用户链接。原始 PDF、归档文件、文献卡、知识卡、配置和安装备份永不属于此自动清理范围。
- 清理后检查实际结果，简报清理数量与必要的保留原因。文件占用或权限拒绝时保留并说明，不改权限、不反复重试；笔记保存成功与缓存清理失败分别报告。客户端或系统要求授权时遵守，不能把技能设置当作越过权限的依据。
