# 保存与恢复写入

仅在保存、初始化写入或排查保存失败时读取。目录边界与证据规则沿用 SKILL.md。


“保存/出卡片/记录一下/保存后暂停”授权保存。其余触发按 [save-policy.md](save-policy.md) 的手动、提醒或已明确开启的自动模式；拒绝保存优先。先区分原文归档和阅读记录。

本文件处理文献保存；明确为概念、名词、工具或方法建卡时走 [knowledge-cards.md](knowledge-cards.md)，不顺带保存论文。保存文献时，若已有相关知识卡片，只读该参考的“关联”补齐链接；没有知识库时跳过，不自动创建知识卡片。

1. 确认项目根和配置路径有效；无配置则读向导和配置模板按默认建最小配置，不重复索取已给的保存授权。目录边界不明先澄清，讲解可继续。
2. 查重优先 DOI/论文标识符，其次规范化完整标题（小写去标点），短名仅作辅助；标题相似不等于同篇。同篇复用编号，增量保存更新原卡片并保留用户手写内容；不同版本记录来源区别，不确定是否替换再问。
3. CORE/REL/METH 各自编号，取索引和卡片文件名中该前缀最大整数加一（只列文件名，不加载全库内容），至少三位；检查目标文件避免覆盖其他论文。分类未知按上述临时分类处理。
4. 索引或链接表缺失时按需创建表头，已有表保留原内容。仅实际获得或保存来源时更新链接表，同一来源不重复追加。文件名移除系统禁用字符并限制长度；用户原文档名保持不变。按 save-policy.md 的归档偏好复制原文或保存用户粘贴正文；不能复制时记录真实来源，不声称 PDF 已落盘。资料不足标实际范围，不编 DOI、作者、结果或链接。
5. 阅读状态与材料范围分开：有全文不等于已精读，用户说读完也不代表缺失部分已补齐。完成所选阅读范围且用户明确结束时记其实际状态；只有核心问题、方法及主要证据已覆盖才标精读，综述/理论论文使用对应证据，不强求系统实验。CORE 用 [完整模板](card-template.md)，REL/METH 用 [简化模板](card-template-lite.md)。只填有证据且已读的部分，其余标“未读/待补”。状态如实标导览/阅读中/筛读/精读；个人判断留给用户，保留已有判断。加入阅读进度。
6. 卡片保存成功后更新索引基础九列（研究线索可按 research-tracks.md 扩展关键词列）：编号、标题（简）、英文标题、DOI/链接、年份、类别、状态、PDF、日期。至少保留真实标题，无本地 PDF 写“无”。配置不重复维护文献表，只更新必要统计。仅 CORE 已精读数用于阶段建议，导览不计精读，篇数不等于能力，不自动升级阶段。
7. 统计从索引实际状态计算，不在重复保存时简单加一；方法工具类也保留独立已读统计。中途失败重试先核对已有文件，不重复建卡或占用新编号。回读核验卡片、索引行及必要配置修改，检查编号和相对链接一致；重复保存复用卡片与索引行。报告实际写入文件，失败报告已完成部分和待重试内容。保存后回显原位置及下一步；单独保存则等待，“保存并继续”或自动换篇保存后继续原任务，暂停则停止。

## 增量保存

文献内容或进度变化时同步更新对应索引日期，供历史关联排序；无变化不刷新日期。会话中已提示过历史关联且配置尚未记录时，本次保存可同步“历史关联状态：已提示”；保留已有“已确认”和明确的 N，不将沉默视为同意开启。

先读取目标卡片相关段，保留未改内容与个人判断；只更新本次新增事实、进度和确认的学习变化，不复制聊天全文。已保存且无变化时说明无需重复写入。回读仅核验改动段、索引行和计数字段。

## 思考成果

保存文献时若已有互动成果，按 [thinking-interaction.md](thinking-interaction.md) 的“思考记录”保存我的理解、待核实问题及研究线索；仅含有内容的项，标明用户提出/AI 建议及未核实状态。可以整理用户在对话中表达的判断，不替用户发明观点，不要求用户打开文件填写。与现有判断、疑问或待办重复时复用原段；未确认的 AI 修正不能记成用户已理解。普通回答本身不触发保存；已开启自动模式则在完整讨论节点保存，无思考成果不读该参考、不建空字段。进度可记录未完成讨论，以便恢复。

研究线索的字段、索引关键词、跨多篇归属及恢复按 [research-tracks.md](research-tracks.md) 处理，不受自动历史 N 限制。

## 紧凑卡片

导览或未读完时只保存元数据、一句话、方法直觉（已讲才填）、关键证据、疑问和阅读进度；未展开的模板章节可省略，用一行列明未读范围。精读时再按原完整/简化模板增量补齐，不先生成大量空标题。已有详细卡片不裁剪。

## 标题显示与原题

- 卡片“标题”按显示偏好填写；另存“原文标题”完整原题，保留大小写和标点。“英文标题”兼容旧索引，仅填实际英文原题，没有则填无，不能把机器英译当原题。查重时临时规范化原题，不改写存储原题。
- 中文优先：使用用户指定中文名，或已核实的官方中文名；否则忠实翻译并标“译名”，不冒充官方标题。中英对照：中文名 + 英文原题；非英文论文则中文名 + 实际原题。无需为了译名额外联网。术语或双关含义不确定时保留相关原词并标待核实。
- 索引“标题（简）”用偏好对应短名，“英文标题”保留查重依据；非英文原题在卡片中保留。新卡片文件名可用中文短名，原始 PDF 不改名。已有卡片切换显示偏好不自动重命名或批量重写；按用户保存指令更新当前记录，保持编号与链接稳定。
- 译名不同不代表不同论文。优先 DOI/标识符及原题查重；旧卡只有规范化英文标题时仍可匹配，不臆造丢失的原题格式。首次保存一个译名后复用，用户纠正时更新显示名。

## 格式校验

公式、表格、链接、编码和 PDF 提取质量统一按 [output-format.md](output-format.md) 检查，适用于所有保存内容。

## 保存后的临时文件

结束本篇或换篇且全部应保存内容成功写入并回读后，按 [output-format.md](output-format.md) 的“完成后自动清理”处理本次生成的未引用缓存。暂停、普通保存节点、保存/归档失败或用户要求保留时不清理；不触碰既有不明缓存。清理失败不否定已成功保存的笔记。
