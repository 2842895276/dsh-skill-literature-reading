# 按需深入阅读

用户选择深入时只读相关模块，不必依次填满。弱点按证据列举，不强凑数量；科研拓展与复现按需提供。教学算例标明非原文。

### 可选分析模块

## A 速览

3 句话（解决什么问题 / 用什么方法 / 做到什么程度）+ 一行「只记一件事」。

## B 定位

问题（一句不带术语的话）/ 相对前作新在哪（引原文 + 标位置）/ 在领域里的位置。

## C 逐节精读

每节两行【在干什么】【关键内容】。铺垫节标「可略读」，关键节标「★精读」。

## D 方法

系统模型或问题建模（角色/输入/输出/约束）+ 假设表 `|#|假设|现实性|塌了会怎样|` + 决策变量 + 3 句话方法核心 + 按理解需要挑关键公式（在算什么 → 符号逐个解释 → 代数字算一遍）。

## E 实验

表格填 评估方式 / 规模 / 工具 / 数据来源 / 基线 / 指标口径 / 最好结果 / **开销算没算**。补三句：能否支撑结论、论文是否比较简单方法及差多少（未比较就写未比较）、最易被攻击的点。

## F 批判

有证据的局限（可检查假设现实性、实验公平性、开销等；无证据不作指控）+ 作者的隐含前提 + 审稿人会要什么补充实验。

## G 创新点

把作者声称的每条贡献归类 —— 真新问题 / 新假设组合 / 新方法套用 / 新系统实现 / 新评估发现 / 工程拼装 —— 再判 实 / 虚 / 半实，给依据。证据足够时指出最有支撑和最需核实的贡献；不必强行凑齐两类。最后给一句向导师说清「这篇新在哪」的话。

## G2 可借鉴

建模方式 / 方法套路 / 实验设计 / 写作结构 / 工程细节 / 可复用资产（代码、数据集、参数表）。每项加一行「**我下周能做什么**」。

## G3 该学什么

概念（3–5 个，各说补到什么程度够用）/ 工具（具体名字）/ 数学（学到什么深度）/ 该先读什么类型 / **明确说"不用学什么"** / 只剩 20 小时的学习顺序。

## H 拓展

能迁移到哪 / 可能结合的方向（按证据选择，说清难在哪）/ 它回避了什么 / 前后脉络（标推测）/ 要做的话 2 个切入点（保守型 + 激进型）。

## I 意义

必读还是选读 / 最小可复现子集 / 下一步读什么类型 / 对课题有什么用。

---


## 论文类型适配

综述优先讲分类框架、覆盖范围和争议；理论论文优先讲命题、条件及证明直觉；定性或非系统论文按其数据和论证方式讲证据。实验表、决策变量、部署规模等不适用时明确省略，不制造缺陷。
