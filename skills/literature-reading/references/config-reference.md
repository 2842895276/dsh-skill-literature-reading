# 配置说明（参考）

> **什么时候读这份**：用户问"某节怎么填""路径怎么改"，或配置有争议时。
> **建配置时不用读**——用 `config-template.md` 就够了。

本页用于解释字段，不是让用户手填的表单。背景了解可选“问答了解”或“边读边了解”（缺字段默认后者），按 [onboarding.md](onboarding.md) 处理；两种方式均由 AI 整理，已知不重复问，未知不猜测。选择方式不改变保存策略。

---

## 一、我的方向

**核心方向**决定什么算 `CORE-`。写一句具体的，不要写"计算机"。

好例子：
- 边缘计算的部署方向
- 分布式系统的容错机制

坏例子：
- 计算机（太泛，什么都是 CORE-）

---

## 二、当前阶段

| 阶段 | 判定（只算 CORE-） | AI 该怎么讲 |
|---|---|---|
| 0 零基础 | 精读 < 5 篇 | 每个术语都解释；跳过数学；多用类比 |
| 1 入门 | 精读 5–14 篇 | 术语只首现解释；公式讲"在算什么" |
| 2 有基础 | 精读 15–29 篇 | 假设知道常见缩写 |
| 3 熟悉 | 精读 30+ 篇 | 直接讲差异和争议 |

篇数区间只用于建议，不自动判定能力或阶段；导览和阅读中不计入已精读。**阶段只能用户确认才升。** REL/METH 不计入 CORE 篇数，但可作为具体概念掌握的证据。

---

## 三、我的背景

这一节**直接决定讲法**，不是装饰。

| 字段 | 影响 |
|---|---|
| 已具备 | 不解释这些内容，直接用 |
| 薄弱 / 没接触过 | 放慢、多类比、先补背景 |
| 最卡在哪 | 那段展开，其他段简略 |
| 讲解偏好 | 优先遵守，盖过默认讲法 |
| 身份 | 决定举例类型（研一用教材例子，工程师用工程例子） |

## 四、知识积累

**只收用户确认搞懂的概念**（能用自己的话说清）。

不收：只是见过名字、还没搞懂的。

## 五、读过的文献

实际内容放在索引文件里，这一节只写一句"见 `<索引路径>`"，避免两处维护。

---

## 六、知识缺口

读论文时"没看懂但重要"的东西，攒着一起补。出现次数按不同论文去重累计，重复保存不增加；已解决后更新状态，不保留为永久薄弱点。

---

## 七、路径配置

### 规则

| 路径类型 | 解释 |
|---|---|
| `./` 开头 | 相对**配置文件所在目录的上一级**（即项目根） |
| 绝对路径 | 解析后须在已确认项目根目录内；项目外路径不直接访问 |
| 目录不存在 | AI 会先创建 |
| 创建失败 | AI 会告诉你具体错误，问要不要换回默认 |

### 常见改法

以下外部路径仅为旧配置示例；若在项目根外，不直接使用，需选择项目内路径或明确重新授权项目边界。

**PDF 放已有文献库**：
```markdown
| 文献 PDF | `D:\我的文献库\PDF` |
```

**卡片放 Obsidian**：
```markdown
| 文献卡片 | `D:\Obsidian\我的库\文献卡片` |
| 索引 | `D:\Obsidian\我的库\文献卡片\00-index.md` |
```

**全部默认**（最省事）：
```markdown
| 文献 PDF | `./papers/` |
| 文献卡片 | `./cards/` |
| 链接总表 | `./links.md` |
| 索引 | `./cards/00-index.md` |
```

### 改路径的注意事项

> ⚠️ **已存的文献不会自动搬过去**，只影响以后的新文献。
> 要搬旧文件，手动剪切粘贴。

## 八、读取策略

“最近 N 篇”只限制自动历史关联，缺省 0（关闭），不限制指定比较或综述。可设 1–2 篇作轻量关联，或 3–5 篇扩展范围；开销取决于卡片内容与实际读取段落，没有固定 KB/Token 保证。先读摘要/进度，有关联再取证据。

“历史关联状态”分未询问、已提示、已确认，区分默认关闭、跳过和明确选择。初始化展示设置入口；开始不同论文且已有其他文献卡时，未提示者收到一次可选提示。“这次”只临时生效，“以后”或设置流程内的明确选择写入配置。旧配置保留 N；提示持久化、筛选、恢复及异常规则见 [history.md](history.md)。

---

## 九、给 AI 的额外指令

用户保存的阅读偏好；不扩大文件权限，也不能覆盖当前会话要求和系统规则。

例：
- "讲实验时重点说为什么这么设计，不用罗列所有数字"
- "我的方向偏工程，多给落地视角"

---

## 最小配置

不想填这么全？三行也能用：

```markdown
# 文献阅读配置

**核心方向**：边缘计算的部署方向
**当前阶段**：0 零基础
**文献路径**：./papers/
```

AI 暂用初学者讲法，不据此确认能力阶段；路径相对已确认项目根目录，按需补表，历史默认 N=0。

## 十、成长与偏好

当前目标、默认讲法、整体阶段分别维护。用户反馈先在会话内生效，明确保存或更新配置时持久化；阶段建议须用户确认。成长回顾按需读取 [growth.md](growth.md)，不以篇数替代能力证据。

## 十一、标题显示

可选中文优先、中英对照、原文；缺字段沿用原文。说“这篇用中文名”只改变当前论文；“以后论文名都用中文”“记住标题用中英对照”表示保存长期偏好。中文译名与真实原题分开保存，切换语言不产生新论文或新编号。讲解语言不受此设置绑定。

## 十二、知识卡片

“知识卡片”默认 `./knowledge/`，“知识索引”默认 `./knowledge/00-index.md`；旧配置缺字段也使用这两个默认值，查看时不补写配置。目录仅在建卡时按需创建，路径仍受项目根约束。知识卡保存解释、用法和来源，可包含尚未理解的内容；“知识积累/知识缺口”记录学习状态，可链接知识卡，但不复制解释全文。建卡及查看不等于掌握，不计入文献统计。

## 思考互动偏好

可选直接讲解、轻量互动、深入讨论，独立于读法和背景了解方式；缺字段兼容直接讲解，不为补字段自动写配置。首次设置解释三档，可推荐轻量但不默认开启。设置任务中的明确选择或“以后”保存长期偏好；“这次/直接讲/不问了”只影响本次，用户可随时改回。细则见 [thinking-interaction.md](thinking-interaction.md)。

## 保存方式与原文归档

保存方式：手动保存 / 结束或换篇时提醒 / 自动保存进度。新用户默认提醒；旧“用户指令触发”及缺字段保持手动，不自动迁移。原文归档：保存文献卡时归档 / 只保存笔记与来源；收到即归档需另行明确选择。完整触发、临时与长期范围、拒绝优先及失败处理见 [save-policy.md](save-policy.md)。
