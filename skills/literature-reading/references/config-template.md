# 最小配置模板

由 AI 根据建档对话生成，不要求用户手填；仅初始化、明确建立背景档案或首次保存缺配置时生成。默认省略无内容的详细背景表，用户提供时再补；旧完整配置继续兼容，不裁剪用户内容。`<...>` 用真实值替换，未知填未说明。

```markdown
# 文献阅读配置
> 更新时间：YYYY-MM-DD

## 方向与阶段
- 核心方向：未说明
- 阶段：未说明（暂用初学者讲法）
- 阶段确认依据与日期：未说明

## 背景与偏好
- 背景了解方式：边读边了解
- 背景：未说明
- 当前目标：先理解论文
- 讲法：术语首现白话解释，按反馈调整
- 标题显示：原文
- 思考互动：直接讲解
- 保存方式：结束或换篇时提醒
- 原文归档：保存文献卡时归档
- 最近 N 篇：0
- 历史关联状态：未询问

## 路径
- 项目根：<实际已授权目录>
- 文献 PDF：./papers/
- 文献卡片：./cards/
- 索引：./cards/00-index.md
- 链接总表：./links.md
- 知识卡片：./knowledge/
- 知识索引：./knowledge/00-index.md

## 阅读统计
- CORE 已精读：0
- REL 已读：0
- METH 已读：0
- 卡片：0
- 文献清单：见 ./cards/00-index.md

## 知识积累
暂无。按概念记录确认的理解、来源、日期。

## 知识缺口
暂无。按概念记录问题、不同论文出现次数、状态及来源。

## 额外要求
无。
```

相对路径基于项目根，绝对路径也必须在根内。阶段只按用户确认更新；路径和偏好保留用户明确选择。知识表有内容时再建，格式参见 [growth.md](growth.md)；配置字段改为紧凑结构不改变授权及成长规则。

标题显示可设中文优先、中英对照或原文；用户已表达偏好时填其选择，不强制默认。讲解语言与标题显示分别处理。
