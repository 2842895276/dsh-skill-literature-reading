> **怎么用**：首次向导问完后，按这个结构生成 `.literature/config.md`。
> 想知道每节详细怎么填 → 看 `config-reference.md`（**建配置时不用读**）。

---

## 生成时要注意

| 项 | 规则 |
|---|---|
| **路径** | 用用户实际选的路径；没选就用 `./papers/`、`./cards/`、`./links.md`、`./cards/00-index.md` |
| **阶段** | 用户答的 0–3；没答就填 0 |
| **最近 N 篇** | 用户答的数；没答就填 3 |
| **未答的字段** | 填「未说明」，**不要编** |
| **目录** | 生成配置后，顺手建好 `<PDF目录>` 和 `<卡片目录>` |

> 每节详细说明和常见改法见 `config-reference.md`。
