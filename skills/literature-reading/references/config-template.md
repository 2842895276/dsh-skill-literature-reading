## 七、路径配置

> **这一节决定文件存在哪。**
> 相对路径（以 `./` 开头）相对**配置文件所在目录的上一级**（即项目根）。
> 绝对路径（如 `D:\我的文献\PDF`）直接用。
> **改完这一节，AI 会按新路径读写。**

| 项 | 路径 | 说明 |
|---|---|---|
| 文献 PDF | `./papers/` | 原文 PDF 存放处 |
| 文献卡片 | `./cards/` | 每篇一张卡片 |
| 链接总表 | `./links.md` | 没 PDF 时记链接 |
| 索引 | `./cards/00-index.md` | 卡片总目录 |

### 常见改法

**把 PDF 放到已有的文献库**：

```markdown
| 文献 PDF | `D:\我的文献库\PDF` |
```

**卡片放到 Obsidian 库**：

```markdown
| 文献卡片 | `D:\Obsidian\我的库\文献卡片` |
| 索引 | `D:\Obsidian\我的库\文献卡片\00-index.md` |
```

**全部放默认**（最省事）：

```markdown
| 文献 PDF | `./papers/` |
| 文献卡片 | `./cards/` |
| 链接总表 | `./links.md` |
| 索引 | `./cards/00-index.md` |
```

## 八、读取策略

> **这一节决定每次读论文时加载多少历史，直接影响 token 开销。**

| 项 | 值 | 说明 |
|---|---|---|
| **最近 N 篇** | `3` | 每次读新论文时，额外读最近 N 篇的卡片。`0` = 完全不读，最省 |

### 怎么选 N

| N | 效果 | 每次额外开销 |
|---|---|---|
| `0` | 每篇独立，互不关联。最省 token | 0 |
| `1` | 能说"和上一篇比"，但再往前就不知道了 | 约 2KB |
| **`3`（默认）** | 能覆盖最近几次阅读，够用 | 约 5KB |
| `5` | 上下文最连续 | 约 10KB |
| `10` | 几乎等于全部回顾，很贵 | 约 20KB |

**建议**：刚开始用 `3`。等你发现自己经常说"和更早的那篇比"，再调大。

### 什么时候会额外读更多

即使 N 很小，下面这些情况 AI 也会按需读更多卡片：

| 情况 | 行为 |
|---|---|
| 你说"我之前读过类似的吗" | 先查索引，命中再读对应卡片 |
| 你说"这几篇有什么区别" | 读你提到的那几篇 |
| 你说"帮我回顾一下" | 读索引，必要时读卡片 |

## 最小配置（懒人版）

如果不想填这么多，只要这三行也能用：

```markdown
# 文献阅读配置

**核心方向**：边缘计算的部署方向
**当前阶段**：0 零基础
**文献路径**：./papers/
```

AI 会按零基础讲，路径全用默认，其他表按需补。

## 只改部分路径

不用全改。比如只把 PDF 放到别处：

```markdown
## 七、路径配置

| 项 | 路径 |
|---|---|
| 文献 PDF | `E:\论文库` |
| 文献卡片 | `./cards/` |
| 链接总表 | `./links.md` |
| 索引 | `./cards/00-index.md` |
```

**没写的用默认。** AI 会先读这一节，缺哪项就按默认值处理。
