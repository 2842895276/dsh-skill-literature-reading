# 最小初始化与渐进了解

仅在明确初始化、或要求保存但缺配置时读取。无配置不阻止论文导览。

1. 依据会话授权和实际访问确认项目根并回显，不猜路径或搜索全局配置。
2. 沿用已知偏好，未说明字段填“未说明”。默认目标为理解论文、初学者友好讲法、历史 N=0；默认讲法不代表确认的能力阶段。
3. 读取 config-template.md，在项目内建 `.literature/config.md`。默认路径 `./papers/`、`./cards/`、`./links.md`、`./cards/00-index.md`；需要保存时才建相应目录和表，不创建空论文卡片。
4. 简短回显实际目录及偏好，提示以后直接说想改什么。有论文立即回到阅读，不再问是否开始。

不做三轮问卷。保存分类不明确时才问一个分类问题；其他信息随用户主动说明逐步补充。用户说跳过、默认或不知道就继续。

已有配置保留偏好，不擅自重置。旧配置指向项目外时不直接访问，说明边界并请用户选项目内位置。写入失败如实报告，仍可继续讲解。
