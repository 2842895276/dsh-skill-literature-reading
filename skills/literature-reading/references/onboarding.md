# 首次使用向导

> **什么时候读这份文件**：用户第一次用（找不到 `.literature/config.md`）时。
> 已经建过配置的话，不用读这份。

---

用户第一次用时，**分三轮问，但每轮都可以跳过**。

> **总原则**：问得越细，后面讲得越准；但**不能让用户觉得在做问卷**。
> 每轮都明说"不想答可以跳过"，用户说跳过就立刻进下一轮。

---

## 第一轮：方向与背景（最重要）

一次问完，等用户回答。**这五个问题的答案决定后面所有讲解方式。**

```
这是第一次用。我需要了解你的情况，这样讲论文时才能对上你的背景。

1. 你的研究方向是什么？
   （一句话，如"边缘计算的部署方向"）

2. 你的身份/阶段？
   （如：研一 / 研二 / 博一 / 高年级本科生 / 工程师转科研）

3. 你学过哪些相关课程？
   （如：计算机网络、操作系统、数据结构；没有就说没有）

4. 你会什么工具/语言？
   （如：Python 熟、C 会一点、Linux 能用；没有就说没有）

5. 你在哪方面最薄弱？
   （如：数学公式、分布式系统、机器学习；说不清就写"不清楚"）

这五个答完，我就能按你的实际情况讲。不想细答的话，只说第 1 条也行。
```

**如果用户只答了第 1 条**：
- 不要追问，按「零基础」处理
- 在配置里把 2–5 记为「未说明」
- 后续读论文时，如果发现讲法不合适，主动问"要不要补充你的背景"

---

## 第二轮：读文献的习惯（可选）

```
再问三个小问题，答不上来直接跳过：

6. 你现在的水平？
   0 零基础（几乎没读过论文）
   1 入门（读过一些，能看懂摘要）
   2 有基础（读过较多，能对比同类工作）
   3 熟悉（有自己的判断）

7. 你读文献最卡在哪？
   如：看不懂方法 / 看不懂实验 / 分不清哪些重要 / 读完就忘

8. 你更想要哪种讲法？
   a 大白话，术语都解释
   b 正常学术讲法，术语只在首次解释
   c 直接讲要点，不用铺垫
```

---

## 第三轮：文件路径与读取策略（可选）

```
最后两个小问题，都可以直接跳过：

【文件存哪】
  papers/        文献 PDF
  cards/         文献卡片
  .literature/   配置文件
  links.md       链接总表

  直接回"不用" = 全部默认
  或告诉我哪个要换，如："PDF 放 D:\我的文献库"

【每次读新论文时，要不要带上最近几篇的历史？】
  0  = 不带，每篇独立（最省 token）
  3  = 带最近 3 篇（默认，推荐）
  5+ = 带更多，上下文更连续但更贵

  直接回车 = 3
```

---

## 关键规则

- **默认值就是现有结构**，用户不填就用默认
- **可以只改其中几个**，不用全改
- 用户说"不用""默认就行""随便""跳过"，**立刻停止追问**
- **不要为了问背景而卡住流程**——用户只想快点开始读论文
- **不要重复问**：配置里已经有的，不要再问
- **不要一次把三轮全倒出来**，一轮一轮来
- **「最近 N 篇」不填就用 3**，不要追着问

---

## 建配置

拿到答案后，创建 `.literature/config.md`。

模板见 `references/config-template.md`。

**把用户的回答填进对应字段**：

| 用户回答 | 填到配置的哪一节 |
|---|---|
| 研究方向 | 一、我的方向 |
| 身份/阶段 | 三、我的背景 → 身份 |
| 学过课程 | 三、我的背景 → 已具备 |
| 会什么工具 | 三、我的背景 → 已具备 |
| 最薄弱 | 三、我的背景 → 薄弱 |
| 水平 0–3 | 二、当前阶段 |
| 读文献最卡 | 三、我的背景 → 读文献习惯 |
| 偏好讲法 | 三、我的背景 → 讲解偏好 |
| 文件路径 | 七、路径配置 |
| 最近 N 篇 | 八、读取策略 |

**目录不存在就先创建**（`papers/`、`cards/`、`.literature/`）。

建完告诉用户：

```
✓ 配置已建好：.literature/config.md

我记住的：
  方向：边缘计算的部署方向
  背景：研一，学过计算机网络/操作系统，Python 熟
  薄弱：数学公式看不懂
  水平：0 零基础 → 我会把每个术语都解释，跳过数学

现在可以直接说「读这篇论文」+ 附 PDF。
以后想改，直接跟我说，或改配置文件。
```

**回显你记住的内容**——这让用户知道 AI 真的读懂了，而不是走个流程。
