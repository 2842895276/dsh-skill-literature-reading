# 通用术语速查

> 读论文时遇到不认识的方法类术语，查这里。
> **领域专有术语**（你研究方向的）请自己往配置文件的「知识积累」里加。

---

## 研究方法类

| 术语 | 全称 | 一句话解释 |
|---|---|---|
| Survey | — | 综述。系统梳理一个领域的现状，适合入门第一篇读 |
| Baseline | — | 基线/对照组。你要打败的那些方法 |
| Ablation Study | 消融实验 | 把自己的方法拆开，逐个验证每个部件的作用 |
| Sensitivity Analysis | 敏感性分析 | 改变某个参数，看结果变化多大 |
| Trace | — | 真实系统采集的负载/资源记录，用来驱动仿真 |
| Testbed | — | 用真实硬件搭的实验环境 |
| Workload | — | 工作负载，系统要处理的那些任务/请求 |
| Overhead | 开销 | 方法本身带来的额外代价（时间、内存、通信） |
| Reproducibility | 可复现性 | 别人能不能用你给的信息重做出同样的结果 |

## 评价指标类

| 术语 | 全称 | 一句话解释 |
|---|---|---|
| Latency | 时延 | 从发出请求到拿到结果的时间 |
| Throughput | 吞吐量 | 单位时间能处理多少任务 |
| Makespan | — | 一批任务全部完成所需的总时间 |
| JCT | Job Completion Time | 单个作业从提交到完成的时间 |
| P99 | 99 分位 | 99% 的请求都在这个时间内完成；比平均值更能反映真实体验 |
| Tail Latency | 尾时延 | 慢的那一小部分请求的时延，往往是用户真实感受 |
| SLO | Service Level Objective | 对时延/可用性的量化目标，如"P99 < 50 ms" |
| SLA | Service Level Agreement | 服务等级协议，SLO 是它的量化表达 |
| Utility | 效用 | 用一个数值概括"这个方案有多好" |
| Fairness | 公平性 | 资源分配是否照顾到弱势方 |

## 优化方法类

| 术语 | 全称 | 一句话解释 |
|---|---|---|
| Convex Optimization | 凸优化 | 一类有全局最优解、且能高效求解的优化问题 |
| LP / ILP / MILP | 线性/整数/混合整数线性规划 | 目标函数和约束都是线性的；整数变量让它变难 |
| NP-hard | — | 一般认为没有高效精确解法的问题类 |
| Heuristic | 启发式 | 不保证最优、但能快速给出"还不错"解的方法 |
| Greedy | 贪心 | 每步都选当前看起来最好的，快但可能短视 |
| Approximation Ratio | 近似比 | 近似解与最优解差距的上界 |
| Lagrangian Relaxation | 拉格朗日松弛 | 把难约束"搬进"目标函数，换取可解性 |
| KKT Conditions | KKT 条件 | 带约束优化问题达到最优的一阶必要条件 |
| Lyapunov Optimization | 李雅普诺夫优化 | 用队列积压加权做在线决策，专门对付"不知道未来" |
| Game Theory | 博弈论 | 多个自利决策者互相影响时的分析方法 |
| Nash Equilibrium | 纳什均衡 | 谁单方面改变策略都不会更好的一种稳定状态 |

## 学习方法类

| 术语 | 全称 | 一句话解释 |
|---|---|---|
| RL / DRL | (深度)强化学习 | 通过与环境交互、试错来学决策策略 |
| MDP | 马尔可夫决策过程 | 把序贯决策建模成"状态-动作-奖励"的框架 |
| Supervised Learning | 监督学习 | 有标注数据，学从输入到输出的映射 |
| Federated Learning | 联邦学习 | 数据留在本地，只上传模型更新 |
| Transfer Learning | 迁移学习 | 把在一个任务上学到的知识用到另一个任务 |

## 系统与工程类

| 术语 | 全称 | 一句话解释 |
|---|---|---|
| Container | 容器 | 打包应用及其依赖的轻量级隔离环境 |
| Kubernetes / K8s | — | 容器编排系统，管部署、扩缩容、调度 |
| Serverless / FaaS | 无服务器/函数即服务 | 按调用计费、自动伸缩；主要问题是冷启动 |
| Cold Start | 冷启动 | 函数/容器首次调用要拉镜像、起运行时，产生额外时延 |
| Virtualization | 虚拟化 | 用软件模拟出多台独立机器 |
| VNF | Virtual Network Function | 用软件实现、可动态部署的网络功能 |
| SDN | Software-Defined Networking | 把网络控制逻辑从硬件里抽出来，用软件集中管理 |
| NFV | Network Function Virtualization | 网络功能虚拟化，是"可编排"的基础设施前提 |
| Edge / Fog / Cloud | 边/雾/云 | 计算资源越靠近用户越"边"，越集中越"云" |

## 论文写作类

| 术语 | 含义 |
|---|---|
| Related Work | 相关工作。作者认为前人差在哪，通常也是你找 gap 的地方 |
| Contribution | 贡献。作者声称自己做了什么新东西，要看是实是虚 |
| Motivation | 动机。为什么这个问题值得研究 |
| Threat to Validity | 有效性威胁。作者自己承认的局限 |
| Future Work | 未来工作。作者没做完的，常是你可以接着做的 |

> **加词条的方法**：读论文时遇到不懂的，先问 AI，确认理解后追加到本表或配置文件的「知识积累」里。
