# 历史关联与阅读偏好

历史关联是读取本项目已保存的文献卡片，不是永久聊天记忆。沿用入口的权限、证据与最少读取规则。

## 发现与设置

初始化简报当前历史设置（新配置关闭 N=0）及“设置阅读偏好”入口，不要求当场选择。首次展示/设置时按 [interaction-guide.md](interaction-guide.md) 为标题显示、背景了解方式、历史关联附上简短用途和例句；用户改哪项就处理哪项，不强制逐项填写；查看设置不写文件。

入口已解释历史关联时即在会话标为已提示，不在开始阅读后重复提醒。仅入口未覆盖、开始一篇不同论文且索引或会话记录已确认有至少一篇其他文献卡时，若尚未提示，在当前阅读主题结束后简短提示一次：“可开启近期论文关联，例如最近 2 篇；也可保持关闭。”不提前读取历史正文，不等待回答才继续阅读；有其他待答问题时延后。恢复同篇、首次保存、查知识卡不触发。

字段“历史关联状态”取未询问/已提示/已确认。“已提示”表示提示过但未选择，或用户跳过；“已确认”表示明确选择 N（包括关闭 0）。后两者均不再主动提示，用户仍可随时设置。展示提示后先在会话记已提示，下次获保存/初始化/配置更新授权时同步；只为记录提示不写文件。未持久化且新会话缺记录时无法保证跨会话只提示一次，不假称记住。

“这次参考最近 3 篇”仅当前论文任务生效；“以后参考最近 3 篇”、设置入口中的明确选择、对长期设置提示的回答才更新配置和已确认状态。未说明范围的阅读指令按本次处理，不默默改长期值。更新配置缺失时按 [onboarding.md](onboarding.md) 建最小配置，不插入背景问卷；写入失败说明仅本次生效。用户不回答保持原 N，不能把沉默当开启授权。

N 为非负整数；非法值需澄清，未得到有效值前沿用原设置。“开启”却没指定数量时建议 2 并询问，不自行保存该值。N>10 简短说明开销并建议缩小，明确要求则遵从；上下文不足时分批读取并说明实际范围。N=0 仅关闭自动加载，当前会话已有材料及指定比较仍可使用。

## 选择与读取

- 仅开始新论文时自动关联；按索引记录的最近保存/更新日期倒序选最多 N 篇不同文献，排除当前论文及其重复版本，不含知识卡。日期相同按编号稳定排序；缺日期的排在末尾，不猜时间。导览/阅读中卡片也可选，但比较仅用已记录内容。更新正文时保存流程同步索引日期；无变化不刷新日期。
- 先取标题、一句话、已读范围/进度；相关时再读方法、实验或结论证据，不默认加载完整卡片或 PDF。无关系不强凑比较；不能仅凭摘要认定两篇结论相反，需核对条件和证据。上下文可复用时不重复读取。
- 历史不足 N 用实际数量；卡片缺失/不可读时跳过并简报，可从剩余候选补足至 N。索引缺失时只定向搜索卡片元数据，不扫描全库正文；查阅不自动修复。找不到指定论文时说明缺失，不编内容。
- 恢复同篇只取当前卡，不因 N>0 重载其他论文；用户明确要求比较时除外。指定比较或全库综述不受自动 N 限制，按指定范围先搜索引再取命中卡证据，不无条件全量读库。

## 旧配置

已有 N 保留。缺状态但 N>0，或已有明确用户选择证据，按已确认处理；N=0 且无选择证据按未询问，出现另一篇文献卡后才提示一次。缺 N 默认 0，不为迁移自动写文件；下次授权写配置时补字段。各项目独立，不读取其他项目历史。

## 指定恢复研究线索

N 不是保存上限或过期删除规则。指定论文/选题检索包括 N=0 均按 [research-tracks.md](research-tracks.md)，先索引后命中段；同会话未保存材料仍可比较。
