# 文献阅读助手

先理解论文，再按需要深入；保存阅读进度，让讲解随你的学习逐步调整。

[English](README.md) | 中文

## 主要功能

- 收到论文先做约 300–500 字导览：问题、意义、方法直觉、关键证据和阅读建议。无需先填背景问卷。
- 用自然语言继续、举例、展开、跳过、总结、保存或暂停；也可直接指定方法、实验、创新点或复现。
- 保留 CORE（核心方向）、REL（相关方向）、METH（方法工具）分类，三类都能深入阅读。
- 记录确认过的概念、疑问和偏好；能力阶段由用户确认，不按篇数自动升级。
- 标题可选中文优先、中英对照或原文；译名注明来源性质，原题保留用于检索和查重。
- 历史卡片默认 N=0，参考资料按需读取，已读内容复用，卡片增量补齐。

## 开始使用

将完整的 `skills/literature-reading/` 文件夹提供给能够读取本地文件的助手，明确让它读取 `SKILL.md`，并确认实际文献项目目录的访问权限。保留 `references/`，只复制入口会缺少保存与成长流程。目录访问和自动发现能力取决于所用客户端。

现有 DSH 安装入口保留：Windows 可运行 `install/install.cmd`，也可将完整技能目录复制到项目的 `.dsh/skills/`。具体步骤见 [快速上手](QUICKSTART.md)。

```text
读这篇论文，先帮我理解它解决什么问题。[附 PDF]
方法没听懂，举个例子。
以后论文名称都用中文。
保存当前进度后暂停。
```

没有配置也可先读论文；明确初始化或首次保存时才建立配置。单说“暂停”“总结”不会写文件。跨会话恢复依赖已保存的进度。

## 保存与成长

保存时查 DOI/标识符及原题，同篇复用卡片和编号，不重复计数。卡片只记录已读内容、证据、疑问和下一步，不要求填满模板。用户自己的判断可以稍后补充。

用户反馈立即影响本次讲法；保存或明确更新配置后，后续会话才能复用。学过的概念可回到待巩固；准备科研时可直接启用深入分支，不要求达到固定篇数。

## 数据与权限

```text
your-project/
├─ .literature/config.md
├─ papers/
├─ cards/00-index.md
├─ cards/<编号>-<短名>.md
└─ links.md
```

数据仅在明确授权的项目范围内读写；不修改原始论文。配置中的路径不扩大授权，访问失败会报告。上述根目录个人数据已由 `.gitignore` 排除；`example/` 只是示例，不是用户档案。
