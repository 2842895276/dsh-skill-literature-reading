# 文献阅读助手

面向使用者的对话示例见 [交互使用说明](docs/交互使用说明.md)。

先理解论文，再按需要深入；保存阅读进度，让讲解随你的学习逐步调整。

[English](README.md) | 中文

## 主要功能

- 可选思考互动：直接讲解、轻量互动或深入讨论，练习自己的表达、比较替代方法并探讨研究问题；可随时跳过，保存时按需记录理解与疑问。

- 无论发送论文还是说“文献阅读”，先询问是否完善背景与偏好，再确认读法。设置可跳过，已指定读法不重复问；按需讲清问题、方法和证据，不设统一字数上限。
- 用自然语言继续、举例、展开、跳过、总结、保存或暂停；也可直接指定方法、实验、创新点或复现。
- 保留 CORE（核心方向）、REL（相关方向）、METH（方法工具）分类，三类都能深入阅读。
- 背景了解可选问答或默认边读边了解，由 AI 整理，无需手填配置；记录确认过的概念、疑问和偏好，能力阶段不按篇数自动升级。
- 标题可选中文优先、中英对照或原文；译名注明来源性质，原题保留用于检索和查重。
- 历史卡片默认 N=0，参考资料按需读取，已读内容复用，卡片增量补齐。
- “设置阅读偏好”可调整历史关联；有其他文献卡后提示一次，支持本次或长期设置，指定比较不受自动 N 限制。

## 开始使用

将完整的 `skills/literature-reading/` 文件夹提供给能够读取本地文件的助手，明确让它读取 `SKILL.md`，并确认实际文献项目目录的访问权限。保留 `references/`，只复制入口会缺少保存与成长流程。目录访问和自动发现能力取决于所用客户端。

现有 DSH 安装入口保留：Windows 可运行 `install/install.cmd`，也可将完整技能目录复制到项目的 `.dsh/skills/`。具体步骤见 [快速上手](QUICKSTART.md)。

```text
读这篇论文，先帮我理解它解决什么问题。[附 PDF]
方法没听懂，举个例子。
以后论文名称都用中文。
保存当前进度后暂停。
```

没有配置也可先读论文；明确初始化或首次保存时才建立配置。暂停、结束与换篇按保存方式处理；自动保存需明确开启。跨会话恢复依赖已保存的进度。

## 知识卡片

可自行选择为阅读中遇到的名词、概念、工具或方法建卡，保存解释、作用、用法、例子和疑问。例如：“把这个概念做成知识卡片”“打开贝叶斯优化卡片”“把这个例子补到原卡”。也可先让助手推荐候选，再选择要保存的内容。

知识卡默认保存在 `knowledge/`，同一知识点增量补充，并关联来源文献；建卡不等于掌握，不增加文献阅读统计。仅解释或查看不会写文件，查卡后说“继续读论文”即可返回原主题。详见 [使用手册](docs/manual.md)。

## 保存与成长

保存时查 DOI/标识符及原题，同篇复用卡片和编号，不重复计数。卡片只记录已读内容、证据、疑问和下一步，不要求填满模板。用户自己的判断可以稍后补充。

用户反馈立即影响本次讲法；保存或明确更新配置后，后续会话才能复用。学过的概念可回到待巩固；准备科研时可直接启用深入分支，不要求达到固定篇数。

## 数据与权限

```text
your-project/
├─ .literature/config.md
├─ papers/
├─ cards/00-index.md
├─ cards/<编号>-<短名>.md
└─ links.md
```

数据仅在明确授权的项目范围内读写；不修改原始论文。配置中的路径不扩大授权，访问失败会报告。上述根目录个人数据已由 `.gitignore` 排除；`example/` 只是示例，不是用户档案。

## 临时文件与自动清理

读取 PDF 时可能生成提取文字和页面图片。完成本篇或换篇且应保存内容全部保存成功后，自动清理本次生成、未被引用的缓存；暂停、保存/归档失败或要求保留时跳过。旧缓存和来源不明文件不自动删除，原论文与个人笔记不受影响。可说“这次保留临时文件”。这不是后台定时任务。

更新时重新运行安装器，选择原平台和项目路径；个人配置与文献记录保留，新会话加载新规则。仅修改下载的源码不会自动更新已安装副本。
