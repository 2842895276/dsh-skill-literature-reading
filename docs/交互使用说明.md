# 文献阅读助手：交互使用说明

适用版本：1029 / 0.4.0，更新日期：2026-10-29。

你不需要记住命令或编辑配置文件。直接说需求即可，下面的句子可以直接复制使用。示例中的选项和数值不是自动生效的设置。

## 1. 第一次开始

安装后，在你的文献项目中新建会话，说：

> 文献阅读。

也可以直接附 PDF、链接或摘要。助手应先询问：

> 先完善背景与偏好，还是沿用当前设置直接读？

你可以回复：

- “先通过对话了解我。”
- “研一，本科网络工程，想了解边缘计算部署，为写论文做准备。”
- “先设置阅读偏好。”
- “跳过设置，先粗读这篇。”

问题可以跳过，已经说过的背景不用重复填写。助手负责整理；没有配置也能阅读。用户明确提供的外部文件在工具权限允许时可直接读取，不必仅因盘符不同搬动 PDF；实际权限受限时再处理。

若直接开始总结论文，先确认技能是否加载：说“使用 literature-reading 技能，开始文献阅读”。安装方式见 [快速上手](../QUICKSTART.md)。

## 2. 阅读方式：想读什么

| 选择 | 作用 | 可以这样说 |
|---|---|---|
| A 大致了解 | 理解问题、方法思路、主要发现与价值 | 先粗读，看看值得深入吗 |
| B 正常精读 | 分段理解问题、方法、证据和局限 | 带我认真读懂这篇 |
| C 深挖某节／逐节读 | 指定方法、公式、实验，或按章节推进 | 重点讲方法；从引言逐节读 |
| D 科研分析 | 分析创新点、可借鉴做法与研究问题 | 哪些能借鉴到我的课题 |
| E 补基础 | 先补当前论文需要的概念与方法 | 先解释鲁棒优化 |
| F 准备汇报 | 按背景、问题、方法、结果和讨论组织 | 帮我准备组会汇报 |

只回复一个字母也可以。自然语言更具体时，以你的需求为准；后面随时能改变读法。只有摘要时，助手不能据此编造全文方法和实验。

### 深度：想怎么讲

| 档位 | 含义 |
|---|---|
| 1 入门 | 解释术语、直觉与例子，复杂推导按需展开 |
| 2 标准 | 讲关键公式、假设、方法步骤与证据 |
| 3 深入 | 拆解推导、证明或实现细节，依材料而定 |

这是讲解方式，不是对你的能力评分。A–F 决定阅读目标，深度决定讲法。例如“B，1，从头”表示用入门讲法精读，并不等于只讲摘要。深度和起点都可以不选。

## 3. 阅读中怎样操作

| 你说 | 助手会怎样做 |
|---|---|
| 继续 | 从约定的下一主题继续 |
| 没听懂，换个例子 | 重讲当前点，不擅自推进 |
| 这个公式展开讲 | 解释用途、符号及必要算例 |
| 跳到实验 | 切换到指定部分 |
| 总结一下 | 回顾已讲内容，不凭此认定精读完成；保存另按设置 |
| 直接一次讲完整 | 按范围完整讲解，不强制每段等待 |
| 暂停 | 停止讲解，按保存设置处理未保存内容 |
| 帮助／有哪些功能 | 解释可用功能及示例 |

阅读中显示的 A、B、C 等字母只对应最近仍待回答的菜单，不是永久快捷键。隔了几轮，最好说“回到刚才的部署选题”，不要只说“B”。

## 4. 阅读偏好：各项有什么用

随时说“设置阅读偏好”。只改你选择的项，不需要全部填写。

| 设置 | 作用与选择 | 示例 |
|---|---|---|
| 背景了解 | 先问答，或边读边根据反馈了解；不会凭学历推断具体知识都已掌握 | 先聊聊我的基础 |
| 标题显示 | 原文、中文译名或中英对照；保留原题用于检索 | 以后标题用中英对照 |
| 思考互动 | 直接讲解、轻量互动、深入讨论 | 这次轻量互动 |
| 历史关联 N | 自动参考最近 N 篇已保存文献卡，联系方法与结论；N=0 关闭 | 以后参考最近 3 篇 |
| 保存方式 | 手动、结束或换篇提醒、自动保存进度 | 以后自动保存进度 |
| 原文归档 | 保存文献卡时复制 PDF，或只记笔记与来源；收到即归档需另行明确开启 | 保存笔记时不复制 PDF |

“这次／这篇”只影响当前任务；“以后”或设置任务中的明确选择更新长期偏好。只查看设置不会写文件。

新用户默认历史 N=0、直接讲解、结束或换篇时提醒保存；新配置原文归档默认随文献卡保存。旧用户保留原设置：旧保存字段缺失仍按手动，归档字段缺失且无原授权时只记来源，不会因更新自动扩大保存范围。

## 5. 思考互动：从听懂到形成判断

- **直接讲解**：不主动出思考题，你随时可以提问。
- **轻量互动**：关键处偶尔问一个问题，一篇通常选择 1–3 个节点，不凑数量。
- **深入讨论**：逐步讨论方法理由、替代方案、取舍、证据和研究验证。

例如：

> 助手：如果不用作者的方法，你会先试什么简单办法？
>
> 你：按用户数量决定服务器位置。
>
> 助手：这个办法抓住了需求规模。若预算只够一台服务器，而两个需求密集区相距很远，你会怎样取舍？

可以看原文、请求提示或说“不知道”。助手应解释准确和遗漏之处，不只夸奖，也不马上替你完成全部思考。

“跳过／继续”跳过当前问题；“直接讲，不问了”停止本次主动提问。“以后直接讲解”修改长期偏好。论文没研究某个问题不一定是缺陷，提出想法也不等于已有创新，仍需核实已有工作和证据。

## 6. 知识积累与知识卡片有什么区别

**知识积累是关于你的学习记录。** 正确复述或明确确认理解，可作为对应知识点的依据；疑问记为待补或待巩固。普通交流先在当前会话生效，保存论文、自动保存节点或明确更新档案时才按授权写入。背景建档任务中的回答可直接整理保存。

> 我理解了盒形不确定集的保守性，但还不懂椭球形约束如何转化。更新我的学习档案。

单次回答正确不意味着掌握整个领域。仅说“继续”、选中一个答案、读完或建卡，都不能自动证明掌握；整体阶段不自动升级。

**知识卡片保存的是知识本身。** 包括解释、作用、用法、例子、来源和疑问。由你选择要做哪些卡，不会把所有术语自动入库。

> 把鲁棒优化做成知识卡，重点写用途和简单例子。
>
> 哪些概念值得建卡？我选一下。
>
> 打开之前的鲁棒优化卡。
>
> 把刚才的例子补到原卡。
>
> 继续读论文。

只解释或查看不会自动建卡；同一概念优先更新旧卡。知识卡不计入文献阅读篇数，也不代表你已掌握。

## 7. 什么时候保存

原文归档和阅读记录是两件事：前者保存 PDF 或来源，后者保存文献卡、阅读进度、理解与疑问。磁盘里有 PDF，不代表笔记已保存。

| 模式 | 行为 |
|---|---|
| 手动 | “保存／出文献卡／记录一下”才写入 |
| 结束或换篇时提醒 | 有未保存变化时问一次，确认后才保存 |
| 自动保存进度 | 明确开启后，在完整阅读／讨论节点及结束、暂停、换篇时增量保存 |

刚收到论文不会生成空文献卡。自动保存不逐句写入，也不自动建立知识卡。关闭应用不保证触发保存，只能依赖最近一次成功保存的记录。

> 保存这篇论文的当前进度。
>
> 保存后暂停。
>
> 保存并继续。
>
> 直接切换，不保存上一篇。
>
> 这个想法不要保存。

未读完也能保存，状态应是“阅读中”或“筛读”，不能冒充精读完成。重复保存复用原卡，有变化才更新。保存成功应说明已保存范围和下一步；PDF 复制失败时应单独说明，不把笔记成功等同于 PDF 已归档。

## 8. 暂时不讨论的选题，怎样回来

选择一个分支不会放弃其他已经形成的线索：

> 先比较两篇论文，负载漂移部署选题留着，比较完提醒我回来讨论。
>
> 回到负载漂移部署选题，先判断研究价值，再讨论验证方法。

“留着”只保证当前可用上下文中的保留。跨会话需要保存：

> 把这个选题和下一步保存到对应文献卡，标为待核实研究线索。

线索可包含名称、关键词、来源论文、提出者、已讨论内容、待核实问题和下一步。AI 建议与用户观点分开。已经保存论文，不代表之后新增的选题自动也保存了，应按保存设置记录变化。

## 9. 超出最近 N 篇，还能找回吗

能。N 限制的是自动参考数量，不是保存上限，也不会让旧卡过期删除。

> 找回之前那个负载漂移部署选题，继续上次的研究设计。
>
> 和之前 Baron 那篇论文比较方法。

指定检索不受 N 限制，包括 N=0。助手先找索引，再读匹配卡片；多个结果不确定时让你选。恢复时先说明上次讨论到哪、未解决什么、下一步是什么。

未保存且上下文丢失，就不能保证找回原想法；需要你补充资料。同会话尚在上下文中的论文即使没保存，仍可比较。

## 10. 一段完整使用示例

1. 你：“文献阅读。”并附论文。
2. 助手询问是否完善背景；你：“研一，网络工程背景，先了解边缘部署方向。”
3. 助手解释偏好；你：“中英标题、轻量互动，参考最近 3 篇，换篇时提醒保存。”
4. 助手提供读法与深度说明；你：“A，用入门讲法。”
5. 粗读后你：“方法再深入一点，公式先讲直觉。”
6. 讨论时你：“先继续读，刚才的选题之后再展开。”
7. 你：“保存当前进度、研究线索；鲁棒优化另外做一张知识卡。”
8. 下次你：“继续读这篇论文，从上次位置开始。”或“继续刚才保存的部署选题”。

任何时候都可以说“我不理解这个设置，解释一下再让我选”。界面里的字母、数字和简称应配说明，你不需要先背这份文档。

## 11. 临时文件与公式显示

`tmp/pdfs/` 下的 TXT 是 PDF 提取文字，PNG 是核对公式和图表的页面图片；它们不等于已保存的文献卡或归档 PDF。不要把它们当作阅读进度记录。需要清理时可要求助手检查并清理本次生成的缓存，不要混删原论文与笔记。

公式显示成 LaTeX 文本时可说“检查这份文档的公式格式”；若符号或数字本身错误，则应核对原 PDF 页面。格式规则覆盖文献卡、知识卡、研究线索及导出笔记。

### 自动清理时机

本篇阅读结束或切换论文，且该篇记录成功保存后，助手会自动清理本次生成、没有被笔记引用的提取文字和页面图片。它不是后台定时任务；关闭应用不会自动运行。暂停、保存或归档失败时保留，可说“这次保留临时文件”。原始 PDF、归档、文献卡、知识卡和学习档案不会清理。旧缓存或来源不明的文件不自动删除，清理受实际工具权限约束。
