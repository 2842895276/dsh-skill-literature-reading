# 使用手册

对话内可直接说“帮助”“有哪些功能”或“怎么用”，助手会给出用途和可直接使用的例句。首次进入阅读先询问是否完善偏好，开始分析前选择阅读方式；保存、建卡时解释相关操作。无需预先阅读本文，也不会每轮重复全部功能。

## 阅读

提供 PDF、链接、摘要、正文或说“文献阅读”，都会先询问是否完善背景与偏好。可跳过；完成或跳过后选择 A 大致了解、B 正常精读、C 深挖某节/逐节精读、D 科研分析、E 补基础或 F 准备汇报。只回字母即可，深度和起点为可选补充，例如“B，1，从头”；也接受自然语言。阅读过程中可按当轮菜单选择继续、展开、举例、换部分或暂停，字母以当前菜单为准。已经指定方法、实验或完整解读的，保留要求，设置结束直接执行。材料仅摘要时不会猜测全文细节。

| 表达 | 结果 |
|---|---|
| 继续 | 接下一主题 |
| 举例、没听懂 | 解释当前概念 |
| 展开、跳过 | 调整深度或切换主题 |
| 总结 | 汇总已读及未读范围 |
| 保存 | 写卡片与进度，等待继续 |
| 暂停 | 停止讲解，按保存方式直接停止、提醒或保存后停止 |
| 保存并继续 | 保存后继续讲解 |

## 配置与标题

背景了解是可选的：可以说“先通过问答了解我”，也可以说“直接读论文，边读边了解我”。默认边读边了解，不单独问卷或测验；从你的提问、反馈和复述逐步调整讲解，不凭论文难度推断能力。问答建档中的回答由 AI 保存并回显；阅读中的学习变化在保存或明确更新背景时持久化。两种方式随时可切换，都不需要手动编辑文件。

配置位于实际项目根的 `.literature/config.md`。未说明背景时暂用初学者讲法，不判定能力。标题显示可选中文优先、中英对照、原文；“这篇用中文名”临时生效，“以后都用中文名”更新长期偏好。译名不替换真实原题，不改变论文身份。

## 卡片与恢复

保存允许导览或阅读中状态；只填已获证据，不要求完成全模板。CORE/REL/METH 都可以深入。同篇增量保存复用编号，保留用户判断，重复保存不增加篇数。新会话指定论文后读取卡片中的已读范围、当前主题、疑问和下一步；没保存过的精确进度无法保证恢复。

## 知识卡片

知识卡片保存名词、概念、工具和方法的解释、作用、用法、例子、适用条件及疑问，与文献卡片独立。可以说：

- “把这个概念做成知识卡片。”
- “这一段哪些值得建卡？我选一下。”
- “打开贝叶斯优化的知识卡片。”
- “把刚才的例子补到这张卡片里。”
- “列出我保存的方法卡片。”
- “继续读论文。”

单说“解释一下”或查看卡片不会保存。推荐建卡时先给候选，用户选择后再写；同一知识点复用原卡，不同领域的同名概念分别记录。知识卡默认保存在 `knowledge/`，通过名称、别名和类型查找；未建卡会如实说明。旧配置无需迁移，首次建卡才创建目录。

卡片区分通用解释与各篇论文的用法。已有文献卡时建立双向链接；论文未保存时先记录真实来源，以后保存文献再补关联。建卡不顺带保存论文，不增加文献计数，也不表示已掌握。阅读中查卡后可回到原主题；跨会话的论文进度仍需明确保存。

## 成长

用户明确反馈、正确复述及真实疑问用于调整讲法。保存时同步确认的学习变化；“记住偏好”可直接更新配置。阶段升级需要确认，篇数只辅助建议；遇到困难可以重新补基础。用户准备科研时可直接进入创新点、比较或复现分支。

## 节省上下文

历史默认 N=0，比较时指定论文或开启最近 N 篇；已有明确设置保留。按标题读取配置及参考片段，卡片不存聊天逐字稿。必要证据和用户判断不会为减少篇幅而删除。

说“设置阅读偏好”可查看并修改标题显示、背景了解方式和历史关联，无需逐项设置。初始化会显示历史关联的当前值；开始不同论文且已有其他文献卡时，尚未提示者会收到一次可选提醒，明确关闭或跳过后不反复问。提示记录在下次保存时写入，未保存就换会话可能再次提示。

“这次参考最近 3 篇”仅当前论文任务生效；“以后参考最近 3 篇”保存长期偏好。自动读取按最近保存/更新日期选择不同论文，排除当前篇；不足 N 用实际数量，先读摘要，有关系再取证据。恢复同篇不自动加载其他论文；指定比较与全库综述不受 N 限制，按任务范围检索。关闭自动关联不清除当前对话已有材料。

## 权限与旧配置

路径必须解析到已授权项目根内；符号链接也不能扩大边界。旧配置缺字段按默认解释，获得保存指令后才补充必要字段。文件操作失败报告已完成部分，不冒充保存成功；已有材料仍可继续阅读。

## 思考互动

与 A–F 读法独立，可选直接讲解、轻量互动、深入讨论；首次偏好入口解释用途，可推荐轻量但不自动开启。未选择及旧配置缺字段均直接讲解。可说“这次深入讨论”“以后轻量互动”，分别影响本次和长期偏好。

互动先讲必要知识，再一次问一个问题：用自己的话解释、为什么选这个方法、是否有替代办法、有什么取舍、改变条件会怎样、如何验证后续研究。回答后具体反馈，必要时给提示；想不到可以看原文、请求选项或跳过，不评分，不要求每篇提出创新点。论文没有涉及某个场景不自动等于缺陷。

思考题与操作菜单不同时等待；“继续/跳过”推进，“直接讲”停止本次提问，暂停立即停止。保存时有内容才整理“我的理解、待核实问题、研究线索”，标明用户提出或 AI 建议，不把 AI 的答案当成用户已掌握。

## 保存与找回研究线索

保存方式可选“手动保存”“结束或换篇时提醒”“自动保存进度”。新用户默认提醒，旧设置沿用，旧配置缺字段仍手动。自动模式需明确选择，例如“以后自动保存进度”；只在完整阅读/讨论节点及结束、暂停、换篇时有变化才写入，不逐句保存。明确“不要保存”优先。关闭应用不能保证触发保存。

原文归档独立选择“保存文献卡时归档”或“只保存笔记与来源”；收到即归档需明确启用。归档 PDF 不等于保存了阅读记录，无法复制时如实说明。自动保存不自动建知识卡，也不认定已精读或掌握。

选“先 A”可以保留其他已有选题在本次讨论中，之后说“回到〈选题名〉”；只有明确要求才在完成当前分支后提醒。要跨会话继续，可说“保存这个选题和下一步”。研究线索存于对应文献卡，含名称、关键词、来源、提出者、已讨论、待核实和下一步；不另建独立选题库。

历史 N 只限制自动关联，不限制保存数量、保留期限或指定检索。即使 N=0，也可说“继续之前的负载漂移部署选题”。先查索引，必要时关键词搜索卡片相关段落；多项命中再选，不全量加载全库。未保存且上下文丢失时不能保证恢复。已保存论文不代表后来讨论的新选题已保存。

## 临时文件生命周期

TXT 是 PDF 提取文字，页面 PNG 用于核对公式和图表。助手应首次生成时说明用途，并按论文和任务分目录管理。它们不是阅读进度或原文归档。

结束本篇或换篇，且应保存的笔记、进度、线索及需要的原文归档全部成功后，可自动清理本次明确创建、未被笔记引用的缓存。普通保存节点、暂停或保存后暂停、拒绝保存、保存/归档失败时保留。用户可说“这次保留临时文件”。

没有准确生成清单的旧缓存不自动清理；原始 PDF、归档、文献卡、知识卡、配置和安装备份均不在范围内。文件占用、权限受限或引用关系不明时保留并报告，不妨碍已经成功保存的记录。无后台定时清理，关闭应用不保证执行。

更新源码后仍需通过安装器更新原安装位置，再以新会话使用。只新增说明不会自动改变已运行会话中的规则。
