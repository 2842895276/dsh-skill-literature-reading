## 一、安装

### 前置条件

你需要 **DeepSeek Harness**（简称 DSH）。没有的话先装它。

### 方式 A：装到单个项目（推荐新手）

**适合**：只想在一个项目里用。

```
① 下载 ZIP
   GitHub 页面 → 绿色 Code 按钮 → Download ZIP

② 解压

③ 复制文件夹
   把 skills/literature-reading 整个文件夹
   复制到：你的项目/.dsh/skills/literature-reading

④ 完成
```

**最终目录长这样**：

```
你的项目/
└─ .dsh/
   └─ skills/
      └─ literature-reading/
         ├─ SKILL.md
         └─ references/
            ├─ config-template.md
            ├─ card-template.md
            ├─ card-template-lite.md
            └─ glossary.md
```

**⚠️ 最容易错的地方**：必须**在这个项目文件夹里**打开 DSH 对话。
在别的文件夹打开是看不到的。

### 方式 B：装到全局

**适合**：所有项目都想用。

双击 `install/install.cmd`。

它会复制到 `C:\Users\你的用户名\.agents\skills\literature-reading\`。

装完**必须重启 DSH**。

### 验证装好了没

新建对话，输入：

```
读这篇论文
```

**如果技能生效**：它会先问你三个问题。

**如果没生效**：它会问"你想让我做什么"或者直接说"请提供论文"。

没生效的话看[常见问题](#七常见问题)。

## 二、第一次使用

### 技能会分三轮问你，每轮都能跳过

> **为什么问这么多**：AI 要知道你的背景，才能决定讲多深、解释哪些术语、跳过哪些内容。
> 但**不想答可以跳过**，跳过的按"零基础"处理。

---

### 第一轮：方向与背景（最重要）

```
这是第一次用。我需要了解你的情况，这样讲论文时才能对上你的背景。

1. 你的研究方向是什么？
   （一句话，如"边缘计算的部署方向"）

2. 你的身份/阶段？
   （如：研一 / 研二 / 博一 / 高年级本科生 / 工程师转科研）

3. 你学过哪些相关课程？
   （如：计算机网络、操作系统、数据结构；没有就说没有）

4. 你会什么工具/语言？
   （如：Python 熟、C 会一点、Linux 能用；没有就说没有）

5. 你在哪方面最薄弱？
   （如：数学公式、分布式系统、机器学习；说不清就写"不清楚"）

这五个答完，我就能按你的实际情况讲。不想细答的话，只说第 1 条也行。
```

**只答第 1 条也行**——后面的按"零基础"处理。

---

### 第二轮：读文献的习惯（可跳过）

```
再问三个小问题，答不上来直接跳过：

6. 你现在的水平？
   0 零基础 / 1 入门 / 2 有基础 / 3 熟悉

7. 你读文献最卡在哪？
   如：看不懂方法 / 看不懂实验 / 分不清哪些重要 / 读完就忘

8. 你更想要哪种讲法？
   a 大白话，术语都解释
   b 正常学术讲法，术语只在首次解释
   c 直接讲要点，不用铺垫
```

---

### 第三轮：文件路径（可跳过）

```
最后，文件想存在哪？不说就全用默认：

  papers/        文献 PDF
  cards/         文献卡片
  .literature/   配置文件
  links.md       链接总表

直接回"不用" = 全部默认。
或告诉我哪个要换，如："PDF 放 D:\我的文献库"
```

---

### 背景信息有什么用

**这不是走流程，是真影响讲法的。**

| 你在配置里写了 | AI 会怎么做 |
|---|---|
| 学过计算机网络 | 讲网络概念时不解释 TCP、带宽 |
| Python 熟 | 代码示例用 Python |
| 数学公式看不懂 | 跳过推导，只讲"这个式子在算什么" |
| 强化学习没接触过 | 遇到 DRL 先花 3 句解释它是什么 |
| 最卡在实验部分 | E 段（实验）展开讲，其他段简略 |
| 偏好大白话 | 所有术语都给生活化类比 |
| 研一 | 举例用课程/教材里的东西，不用工业界案例 |

### 四个可自定义的位置

| 项 | 默认 | 可改成 |
|---|---|---|
| **文献 PDF** | `./papers/` | 任何路径，如 `D:\我的文献库\PDF` |
| **文献卡片** | `./cards/` | 如 Obsidian 库里的目录 |
| **链接总表** | `./links.md` | 任意位置 |
| **索引** | `./cards/00-index.md` | 跟着卡片目录走 |

**相对路径**（`./` 开头）相对项目根目录。
**绝对路径**（`D:\...`）直接用。

### 常见场景

**场景 1：我有自己的文献库**

```
3. 文献 PDF 想存在哪？
   → D:\我的文献库\PDF

其他三个位置要改吗？
   → 不用
```

结果：PDF 存到你的文献库，卡片和配置留在项目里。

**场景 2：我想全放 Obsidian**

```
3. 文献 PDF → 不用，默认
其他三个位置要改吗？
   → 卡片放 D:\Obsidian\我的库\文献卡片
```

结果：卡片进 Obsidian，PDF 留项目里。

**场景 3：懒人模式**

```
1. 边缘计算的部署方向
2. 研一
3-5. 跳过
6-8. 跳过
路径 → 不用
```

结果：全用默认，AI 按零基础讲。

### 如果不想回答

自己建配置文件也行。最小内容：

```markdown
# 文献阅读配置

**核心方向**：边缘计算的部署方向
**当前阶段**：0 零基础
**文献路径**：./papers/
```

保存到 `你的项目/.literature/config.md`。

### 想填详细一点

复制 `skills/literature-reading/references/config-template.md` 到 `.literature/config.md`，按里面的注释填。

### 以后想改路径

打开 `.literature/config.md`，改「七、路径配置」那一节：

```markdown
| 项 | 路径 |
|---|---|
| 文献 PDF | `E:\新位置\PDF` |
| 文献卡片 | `./cards/` |
| 链接总表 | `./links.md` |
| 索引 | `./cards/00-index.md` |
```

**只改要改的那行，其他保持默认。** 改完立即生效，不用重启。

> ⚠️ **已经存过的文献不会自动搬过去**。改路径只影响以后的新文献。
> 要搬旧文件，手动剪切粘贴即可。

## 三、日常使用流程

### 完整流程

```
① 你说：读这篇论文
        [拖入 PDF]
              ↓
② AI：📥 已存档：papers/CORE-001-xxx.pdf
      这是核心方向文献（CORE-）。
      【问题1】这次想干什么？
        a 快速筛  b 正常精读  c 深挖某节
        d 找创新点/可借鉴  e 想补基础  f 准备汇报
      【问题2】要多深？
        a 入门（跳过数学）  b 标准  c 硬核（推导也拆）
      【问题3】先看哪块？
        a 从头  b 方法  c 实验  d 创新点
        e 可借鉴  f 该学什么  g 只看弱点
              ↓
③ 你：b，标准版，从头
              ↓
④ AI：[输出 A 速览 + B 定位]
      要继续吗？下一段是 C 逐节精读和 D 方法拆解。
              ↓
⑤ 你：继续
              ↓
⑥ AI：[输出 C + D]
      要继续吗？
              ↓
    …… 一直到最后一段 ……
              ↓
⑦ 你：出卡片
              ↓
⑧ AI：写卡片 → 更新索引 → 更新档案
```

### 六种常用开场（直接抄）

不想每次思考怎么回答，就用这些：

| 场景 | 直接回这句 |
|---|---|
| 快速判断值不值得读 | `a，入门版，先看 A 和 F` |
| 认真读懂一篇 | `b，标准版，从头开始，一段一段来` |
| 想知道这篇新在哪 | `d，硬核版，先看 G 创新点` |
| 想知道我能抄什么 | `d，标准版，先看 G2，重点讲工程细节` |
| 想知道该补什么基础 | `e，标准版，先看 G3，按"现在该补"排` |
| 要组会汇报 | `f，标准版，先看 A、B、E、F` |

### 你随时可以打断

| 你想做什么 | 说什么 |
|---|---|
| 某段讲太浅 | `D 再讲细一点` |
| 某段不用看 | `跳过 E，直接给我 G` |
| 换个说法 | `刚才那段用大白话重讲` |
| 回头补 | `把 C 的第 3 节再展开` |
| 只问一点 | `这篇用的什么仿真器？` |

**AI 会立刻照办，不会坚持原计划。**

## 四、三种文献分别怎么处理

### CORE- 核心方向（你的正业）

**怎么判断**：直接解决你研究方向的问题。

**AI 会怎么做**：完整九段，深度讲。

**卡片**：完整卡片（九段 + 我的判断）。

**计入水平**：✅ 计入

**例子**：你是"边缘计算部署"，那《边缘服务放置算法》就是 CORE-。

---

### REL- 相关方向（了解性质）

**怎么判断**：邻近领域，有借鉴价值但不是主业。

**AI 会怎么做**：只讲四问，不输出九段：

```
1. 一句话：这论文干什么的
2. 和你的方向有什么关系
3. 有什么可借鉴的（1–2 条）
4. 值不值得深入（是/否 + 理由）
```

讲完会问："要不要细看？还是就到这？"

**卡片**：简化卡片（四行）。

**计入水平**：❌ 不计入

**例子**：你是"边缘计算部署"，那《5G 网络切片综述》就是 REL-。

---

### METH- 方法工具（跨领域）

**怎么判断**：提供通用方法论。

**AI 会怎么做**：只讲两样：

```
1. 这工具是什么、解决什么类型的问题（3 句内）
2. 能怎么用在我的方向上（2 个具体场景）
```

**不讲**来龙去脉、不推导、不追溯源流。

**卡片**：简化卡片。

**计入水平**：❌ 不计入

**例子**：你是"边缘计算部署"，那《深度强化学习入门》就是 METH-。

---

### 为什么这样分

```
读 20 篇 REL-（相邻领域综述）
   ≠
你成为 CORE- 方向的入门者
```

如果档案把它算成"读了 20 篇"，AI 就会按"有基础"讲——你反而更听不懂。

**阶段判定只看 CORE- 篇数。**

## 五、卡片怎么填

### 完整卡片（CORE-）

生成后长这样：

```markdown
---
编号: CORE-001
标题: xxx
...
---

## A 一句话
> 用【方法】解决【场景】下的【问题】，在【指标】上达到【数字】。

## B 它新在哪
...

## C 关键假设
| # | 假设 | 现实性 | 塌了会怎样 |
...

## G 我的判断（必须我自己写）
- 这篇对我有用吗：
- 我信它的结论吗，为什么：
- 它最可疑的地方：
- 读完我想到的新问题：
```

### ⚠️ 最重要的一条

**「我的判断」那一节，AI 只留空，你必须自己写。**

为什么：

- 前面那些事实，AI 都能填，填得比你好
- 但那四行**只有你能写**
- 如果让 AI 写，你只是"看过"这篇论文，不是"读过"

### 怎么写「我的判断」

不要写空话。参考：

| 问题 | 差的回答 | 好的回答 |
|---|---|---|
| 对我有用吗 | "有用" | "它的假设表写法我可以直接套用" |
| 我信吗 | "信" | "只信一半：仿真结果可信，但真实部署那段只有 3 个节点" |
| 最可疑 | "没什么" | "它说开销可忽略，但没给决策耗时数据" |
| 新问题 | "没有" | "如果把节点数提到 100，它的贪心策略还成立吗？" |

## 六、档案怎么成长

### 阶段表

| 阶段 | 判定（**只算 CORE-**） | AI 怎么讲 |
|---|---|---|
| **0 零基础** | 精读 < 5 篇 | 每个术语都解释，跳过数学 |
| **1 入门** | 精读 5–15 篇 | 术语只在首现解释 |
| **2 有基础** | 精读 15–30 篇 | 假设你知道常见缩写 |
| **3 熟悉** | 精读 30+ 篇 | 直接讲差异和争议 |

### 升级规则

- 跨过阈值时，AI 会**问你**要不要升级
- **它不会自己改**（硬性规则 R11）
- 你确认后才升

### 档案还会累积

| 内容 | 作用 |
|---|---|
| **知识积累** | 你确认搞懂的概念 → 下次 AI 跳过解释 |
| **文献表** | 三类分别登记 |
| **知识缺口** | 没看懂但重要的，攒着一起补 |
| **关注方向** | 从"广泛了解"逐渐收窄 |

### 怎么让档案更准

读完一篇后，如果某个概念你真的懂了，主动说：

```
"XX 这个概念我搞懂了，加进知识积累"
```

AI 会问你确认，然后写进档案。下次讲论文时它就不会再解释这个词了。

## 七、常见问题

### 技能没反应

按顺序排查：

**1. 文件在不在**

```
你的项目/.dsh/skills/literature-reading/SKILL.md
```

这个文件必须存在。

**2. SKILL.md 开头对不对**

前几行必须是：

```markdown
---
name: literature-reading
description: 通用文献精读助手...
---
```

`name` 必须和**文件夹名**完全一致。

**3. 工作区对不对**

方式 A 装的，必须**在这个项目文件夹里**开对话。

**4. 重启 DSH**

方式 B 装的必须重启。

**5. 兜底办法**

直接跟 AI 说：

```
读取 .dsh/skills/literature-reading/SKILL.md 并按照它执行
```

技能本质就是一份指令文件，手动让它读也一样。

---

### 它不问我三个问题，直接开始分析

说明技能的「先问后做」规则没生效。

**解决办法**：打断它，说：

```
停。按照技能要求，先问我那三个问题。
```

---

### 它把 REL- 文献也按九段讲了

说明分类判断没生效。

**解决办法**：

```
这篇是相关方向（REL-），按简版四讲就行，不用九段。
```

---

### 档案里的阶段不对

**解决办法**：直接改 `.literature/config.md` 里「当前阶段」那一行，改成你想要的值。

或者跟 AI 说：

```
把阶段改成 1 入门
```

---

### 想换研究方向

改 `.literature/config.md` 的「核心方向」那一行。

已有的文献表不用动——旧的 CORE- 还是 CORE-，新的按新方向判断。

---

### 想删除某个技能

方式 A：删掉 `你的项目/.dsh/skills/literature-reading` 文件夹。
方式 B：删掉 `C:\Users\你的用户名\.agents\skills\literature-reading` 文件夹。

---

### 想改技能的行为

改 `skills/literature-reading/SKILL.md`。

改完重启 DSH 生效。

常见改法：

| 想改什么 | 改哪里 |
|---|---|
| 九段内容 | SKILL.md 的「九段内容」 |
| 分类规则 | SKILL.md 的「判断分类」 |
| 问用户的问题 | SKILL.md 的「问三件事」 |
| 卡片格式 | references/card-template.md |
| 术语表 | references/glossary.md |

## 附录：一天用一次的最短路径

```
① 打开项目文件夹，启动 DSH 对话
② 说「读这篇论文」+ 拖入 PDF
③ 回一句「b，标准版，从头」
④ 一路「继续」
⑤ 读完说「出卡片」
⑥ 打开卡片，填「我的判断」那四行
```

**全程 2 分钟操作 + 你的阅读时间。**
