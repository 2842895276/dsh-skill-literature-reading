# 交互流程审阅（2026-10-26）

## 范围与方法

基于 SKILL.md 与全部 references 做静态一致性检查和场景逐步推演。以下是规则层面的验证，不是独立模型运行或实际论文阅读效果测量；未产生真实用户档案和卡片。官方 quick_validate.py 仍因缺 PyYAML 未运行，未安装依赖。

## 场景推演

| 场景 | 应有路径与审阅结论 |
|---|---|
| 首次附 PDF，无配置 | 直接导览，默认初学者讲法；保存才建配置，无问卷阻塞 |
| 只有摘要或链接无法打开 | 按已获取范围讲解，未获取内容不补编 |
| 用户方向未知 | 先讲；保存时一个分类问题，跳过可暂用 REL |
| 连续说继续、举例、展开、跳过 | 依当前主题和下一步执行；举例不消耗下一主题 |
| 只说总结或暂停 | 不写文件；暂停回显恢复信息，不声称跨会话永久记住 |
| 保存后暂停，再开新会话 | 卡片记录来源、范围和下一步；按指定记录恢复，歧义仅问论文选择 |
| 同篇多次保存 | 复用编号和索引行，保留手写判断，统计重算不累加 |
| 卡片写成、索引失败后重试 | 检查现有卡片和编号，再补索引，不创建重复档案 |
| 说这个懂了，后来又不懂 | 本次讲法即时调整；保存后知识状态可由掌握回到待巩固 |
| 说记住以后少讲基础 | 明确偏好更新可写配置，不要求先达到固定篇数 |
| CORE 篇数跨阈值 | 不自动升级；需能力证据与用户确认，REL/METH 的概念证据仍有效 |
| 开始科研或复现 | 进入已有深入分支，不要求完成入门篇数 |
| 综述或理论论文 | 使用分类框架、命题和论证证据，不强套部署和实验规模 |
| 旧配置缺成长字段或指向项目外 | 缺字段默认兼容，按授权补充；不访问外部路径 |

## 修正结果

补齐成长反馈—会话调整—明确保存—下次复用的闭环；区分讲解深度与整体阶段。修正重复保存计数、失败恢复和编号冲突风险；补充方法直觉卡片及不同论文类型适配；清理深入参考中强凑弱点与贡献的要求。

## 剩余验证

需要以实际 PDF 做一次完整的导览—解释—保存—新会话恢复，才能验证特定运行环境下的 PDF 解析、文件写入及遵循表现。当前技能是指令流程，无法单凭静态检查保证每次模型执行完全一致。

## Token 优化复核

技能入口由 4454 缩至 2227 字符（50%）；配置模板由 1736 缩至 627 字符（约 64%）。这是同次编辑前后的 Unicode 字符数，不是模型 Token 或费用实测。保存细则移到 saving.md，仅保存时加载；深入模块改用可搜索标题。

普通导览路径：入口 + 必要配置片段 + 论文相关部分；不加载保存、成长和完整卡片模板。首次保存路径：再加载保存说明、最小初始化和所需模板。继续阅读复用未变上下文；上下文丢失、内容变化或写入冲突时核对原文件。成长回顾继续按需加载，不为节省开销删除学习证据。

新增规则：默认导览约 300–500 字，明确用户要求优先；导览卡片先保存已讲内容与恢复进度，深入后增量补齐；无变化不重复重写。示例配置去掉重复论文表并明确 N=0。静态检查已覆盖参考链接可达性、编码和代码围栏；未实测特定模型 Token，也未做真实 PDF 跨会话试读。
