# 文献阅读助手 1029 · v0.4.0

发布日期：2026-10-29。

本版恢复先了解需求、再选择读法的阅读流程，并加入知识卡、思考互动、可恢复的研究线索和更明确的保存设置。

## 主要更新

- 统一入口：无论发送论文还是输入“文献阅读”，先询问完善偏好还是直接阅读；已指定的读法不重复询问。
- A–F 阅读方式与三档讲解深度，支持字母和自然语言；首次出现的设置附作用说明。
- 可选轻量互动与深入讨论，帮助用户解释方法、比较替代方案和提出待验证的问题。
- 知识卡支持概念、工具和方法的保存、查看与补充；学习档案只记录有依据的理解变化。
- 手动保存、结束/换篇提醒、明确开启的自动进度保存；PDF 归档独立设置。
- 研究线索保存来源、提出者、疑问和下一步，指定检索不受最近 N 篇自动关联限制。
- 统一公式、表格、编码与链接规范，避免聊天公式标记直接进入 Markdown 后无法渲染。
- 完成阅读或换篇且保存成功后，清理本次生成且未引用的临时文本和页面图片；暂停、失败或要求保留时跳过，不清理旧缓存或用户资料。
- Windows 安装器支持 Codex / DSH、指定项目路径 / 全局安装，备份旧技能并逐文件校验。

## 安装与升级

下载完整仓库或对应发布包，运行 `install/install.cmd`，选择平台及文献项目目录。Codex 项目安装到 `.agents/skills/literature-reading`，DSH 项目安装到 `.dsh/skills/literature-reading`。

更新保留个人配置、论文与卡片。旧保存设置不会变成自动保存；需要时明确说“以后自动保存阅读进度”。安装后新建会话测试，未识别时重启客户端。仅更新源码不会自动更新已经安装的副本。
